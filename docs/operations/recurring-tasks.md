# 定期作業

繰り返し必要になる運営作業と、自動化の有無を記録する。

| 作業 | 現在の状態 | 頻度 | 人による確認 |
|---|---|---|---|
| 今日の石川ニュースの収集・更新 | GitHub Actionsで自動生成 | 毎日朝6時（JST） | 掲載結果や誤取得を必要に応じて確認 |
| 店舗・施設情報の再調査 | 自動化未設計 | 未決定（週次案あり） | 差分を確認してから公開反映 |
| 現地確認リストの整理 | 手動 | 確認結果を得たとき | 管理者が確認結果を提供 |
| 運営バックログの見直し | 手動 | 必要時 | 優先順位と着手対象を管理者が決定 |

## 自動化するときの原則

- 自動収集結果を、そのまま店舗データへ反映しない。
- 新店・閉店・営業時間など重要な変更は、根拠と対象IDを確認する。
- 店舗紹介文をAIで自動生成しない。
- 公開前に管理者の承認が必要な作業を明確にする。
- 実行頻度、失敗時の通知、重複防止、履歴保存を設計してから開始する。
