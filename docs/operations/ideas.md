# 運営アイデア

まだ採用・実施を決定していない案を記録する。検討が具体化したら`backlog.md`へ移し、方針を決めたら`decisions.md`へ記録する。

## 現在の候補

- 石川以外の具志川・勝連・與那城などへの地域展開
- 「駐車場」「公衆トイレ」など生活情報カテゴリの追加
- 新店・閉店の定期的な差分検出
- カテゴリや出典ラベルを利用者に分かりやすく整理
- 読者投稿フォームを使った地域参加型の情報更新
- SNS等を利用したURL共有と地域向け広報

## アイデアを評価する観点

- 石川マップの利用者にどのような価値があるか
- 情報を正確に維持できるか
- 個人運営で継続できる作業量か
- 個人情報や店舗の意向に配慮できるか
- 現在のデータ構造や画面に与える影響
- 公開後に確認・修正できる仕組みがあるか
