# 運営上の決定事項

石川マップの運営について決定した内容と理由を記録する。将来方針を見直すときに、以前の判断理由を確認できるようにする。

## 2026-08-30：Skillと運営資料を分離する

- 決定：Codexの作業手順は`.agents/skills/`、今後の運営計画・保留事項・アイデアは`docs/operations/`に記録する。
- 理由：Skillを作業手順に集中させ、管理者とCodexの双方が運営状況を一覧しやすくするため。
- 補足：`docs/operations/`の未完了項目は、記録だけで自動実行しない。

## 記録形式

新しい決定は次の項目を含める。

- 日付
- 決定内容
- 理由
- 影響するファイル・運用
- 見直し条件（必要な場合）
