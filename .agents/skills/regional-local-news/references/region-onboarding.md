# 新地域のニュース導入手順

## 1. 範囲を確定する

市町村名、対象地区名、旧市町村名、大字・町丁目、境界の根拠を記録する。同名地名や人名がある場合は誤一致語も先に整理する。範囲が曖昧なまま収集条件を作らない。

## 2. 共通8分野を棚卸しする

次を同じ順で確認し、施設・団体・定例行事・公式ページを一覧化する。

1. 行政・自治会
2. 催し・祭り・文化・スポーツ
3. 公共施設（役所、公民館、図書館、体育館など）
4. 教育（学校、幼稚園、保育園、講座）
5. 防災・安全（消防、警察、避難、災害）
6. 健康・医療・福祉・子育て
7. 交通・道路・工事・公共交通
8. 商業・観光・地域活動

施設の存在確認はニュース掲載ではない。施設が発信するイベント、募集、休館、規制などを継続取得できるかを確認する。

## 3. 地域固有テーマを深掘りする

共通棚卸しで繰り返し登場し、地域との関係を公式情報で確認できたテーマだけを深掘りする。例：石川の闘牛。テーマ名だけでなく、会場、主催、公式日程、更新頻度、終了情報まで追える入口を探す。

## 4. 情報源を評価する

優先順位は、自治体・施設等の一次情報、公共機関、報道機関、検索集約、投稿の順。原典URL、発信主体、更新日、取得方法、地域との根拠を残す。検索結果だけで自動掲載を許可しない。

## 5. 停止条件

共通8分野と地域固有テーマについて、異なる検索語で二巡し、新しい有力な一次情報源が増えなければ初回調査を終了する。見つからない分野は「該当なし／未確認」と記録し、推測で埋めない。
