# 石川関連度の判定

候補収集、フィルター変更、誤掲載の原因調査を行うときに読む。

## 考え方

単語の有無だけで即採用せず、地域との関係を示す証拠を加点し、誤一致を減点する。点数は候補の優先順位であり、真偽の保証ではない。

## 初期スコア案

| 条件 | 点数 |
|---|---:|
| 本文・タイトル・住所に「うるま市石川」がある | +60 |
| 「うるま市」と「石川」の両方がある | +40 |
| 石川地区の登録済み施設・学校・自治会名がある | +35 |
| 石川、伊波、嘉手苅、山城、楚南、東恩納、東山、白浜、赤崎、曙の地名があり、沖縄・うるまの根拠もある | +25 |
| 沖縄県またはうるま市の公式発信 | +15 |
| 開催地・住所・主催者のいずれかを原典で確認できる | +15 |
| 「石川県」「金沢市」など他地域が示される | -100 |
| 「石川」が人名だけで、地域根拠がない | -80 |
| 場所が「うるま市」までで石川地区の根拠がない | -25 |
| 原典を開けず、検索結果の要約しかない | -20 |

## 初期判定

- `60点以上`：石川関連候補。自動掲載条件を別途確認する。
- `35〜59点`：管理人確認候補。
- `34点以下`：原則不採用。新しい根拠があれば再判定する。

この閾値は固定の正解ではない。実際の誤掲載・取りこぼし例を保存し、ユーザー確認後に調整する。

## 地域辞書

地名だけでは他地域と衝突するため、必ず沖縄県・うるま市・登録施設などの補助根拠と組み合わせる。

- 地区・大字：石川、石川東恩納、石川伊波、石川嘉手苅、石川山城、石川楚南、石川東山、石川白浜、石川東山本町、石川赤崎、石川曙
- 主要施設例：石川多目的ドーム、石川岳、石川歴史民俗資料館、石川図書館、石川少年自然の家

施設辞書を追加・変更する場合は、正式名称と公式URLを確認する。候補1件のために推測名を恒久辞書へ追加しない。

## 信頼度は別に持つ

`localScore`は地域との関係、`confidence`は情報の確からしさを表す。混同しない。

- 公式原典で日時・場所を確認：高い
- 報道機関1件のみ：通常
- 管理人投稿：投稿者区分を明示して扱う
- 読者投稿・SNSのみ：確認待ち
- 情報源間で日時や場所が不一致：確認待ち

## 重複判定

次を組み合わせ、タイトル冒頭20文字だけに依存しない。

- 正規化した原典URL
- 全角半角・空白・記号を正規化したタイトル
- 開催日または公開日
- 場所・施設名
- 出来事の種類

同じ出来事を別媒体が報じている場合は、一次情報または最も詳しい原典を代表にし、他ソースURLを補助情報として保持できる。
