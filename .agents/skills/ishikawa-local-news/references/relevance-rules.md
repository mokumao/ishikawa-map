# 石川関連度の判定

候補収集、フィルター変更、誤掲載の原因調査を行うときに読む。

## 考え方

単語の有無だけで即採用せず、地域との関係を示す証拠を加点し、誤一致を減点する。点数は候補の優先順位であり、真偽の保証ではない。

## 初期スコア案

| 条件 | 点数 |
|---|---:|
| 本文・タイトル・住所に「うるま市石川」がある | +60 |
| 「うるま市」と「石川」の両方がある | +40 |
| 石川地区の確認済み施設・学校・自治会名が記事内にある | +60 |
| 確認済み施設の専用検索で見つかったが、記事内に施設名がない | +35（判断保留） |
| 石川、伊波、嘉手苅、山城、楚南、東恩納、東山、白浜、赤崎、曙の地名があり、沖縄・うるまの根拠もある | +25 |
| 沖縄県またはうるま市の公式発信 | +15 |
| 開催地・住所・主催者のいずれかを原典で確認できる | +15 |
| 「石川県」「金沢市」など他地域が示される | -100 |
| 「石川」が人名だけで、地域根拠がない | -80 |
| 場所が「うるま市」までで石川地区の根拠がない | -25 |

## 初期判定

- `60点以上`：石川関連候補。日時、リンク、信頼度、慎重な確認が必要な内容かを確認し、条件を満たせば自動掲載する。
- `35〜59点`：判断保留。公開せず監査記録へ残す。
- `34点以下`：原則不採用。新しい根拠があれば再判定する。

この閾値は固定の正解ではない。実際の誤掲載・取りこぼし例を保存し、ユーザー確認後に調整する。

## 地域辞書

地名だけでは他地域と衝突するため、必ず沖縄県・うるま市・登録施設などの補助根拠と組み合わせる。

- 地区・大字：石川、石川東恩納、石川伊波、石川嘉手苅、石川山城、石川楚南、石川東山、石川白浜、石川東山本町、石川赤崎、石川曙
- 主要施設例：石川多目的ドーム、石川岳、石川歴史民俗資料館、石川図書館、石川少年自然の家

施設辞書を追加・変更する場合は、正式名称と公式URLを確認する。候補1件のために推測名を恒久辞書へ追加しない。

## 信頼度は別に持つ

`localScore`は地域との関係、`confidence`は情報の確からしさを表す。混同しない。

- 公式原典で日時・場所を確認：高い
- 報道機関1件のみ：通常
- 管理人投稿：投稿者区分を明示して扱う
- 読者投稿・SNSのみ：確認待ち
- 情報源間で日時や場所が不一致：確認待ち

## 重複判定

次を組み合わせ、タイトル冒頭20文字だけに依存しない。

- 正規化した原典URL
- 全角半角・空白・記号を正規化したタイトル
- 開催日または公開日
- 場所・施設名
- 出来事の種類

同じ出来事を別媒体が報じている場合は、一次情報または最も詳しい原典を代表にし、他ソースURLを`relatedUrls`として保持する。公開画面には代表1件だけを出す。

写真ギャラリーや転載記事では、比較前に次の表示差を取り除く。

- 先頭の`画像7/23＞`、`画像21 / 23＞`などの画像番号
- 先頭の`写真：`、`画像：`
- 末尾の媒体名
- 全角・半角、空白、記号の違い

正規化後のタイトルが同じ候補は同一内容としてまとめる。同じ確認済み施設の候補では、明示された催し名も比較し、媒体ごとに見出しが違う同一催しをまとめる。代表記事は、次の順に優先する。

1. 自動掲載条件を満たす
2. 画像番号などの接頭辞がない
3. 公式・一次情報、次に報道機関
4. 信頼度と地域関連度が高い
5. それでも同じなら新しい

代表以外は`status: duplicate`、`duplicateOf: 代表候補ID`として監査記録へ残す。同じタイトルでも、施設や催し日が異なる場合は別の出来事として扱う。
