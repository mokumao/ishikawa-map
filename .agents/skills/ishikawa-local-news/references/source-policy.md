# 情報源方針

情報源の追加、削除、取得方式の変更を行うときに読む。

## 優先順位

### A：公式・一次情報

- うるま市、沖縄県、警察、消防、公共交通
- 学校、図書館、公民館、資料館などの公式ページ
- 主催者、施設、店舗、地域団体の公式サイト

場所・日時・開催可否などの根拠として優先する。公式であっても古いページや更新日時不明の場合は、現在も有効か確認する。

### B：報道機関

- 地域新聞、放送局、通信社
- Googleニュースは発見経路として使い、可能なら配信元の記事へ到達する

同一記事の転載や画像ページを大量に拾わないよう、正規URLと出来事単位で重複を処理する。

### C：地域投稿・SNS

- 管理人投稿
- 承認済み読者投稿
- 自治会・店舗・地域団体の公式SNS

管理人投稿以外は原則`review`とする。アカウントが公式か、投稿が公開情報か、取得・引用が規約上可能かを確認する。本文全文、画像、動画を転載しない。

### D：発見専用

- まとめサイト、検索結果、イベント集約サイト、個人投稿

候補発見には使えるが、可能な限り主催者や行政などの原典で確認する。原典に到達できなければ`review`または不採用にする。

## 最初に整備する情報源群

- 既存のGoogleニュース検索RSS
- うるま市公式サイト内の石川関連ページ・新着情報
- 石川図書館、石川歴史民俗資料館、石川少年自然の家
- 石川多目的ドーム・闘牛関連の公式発表
- 石川地区の学校、公民館、自治会に公開更新情報がある場合はその公式ページ
- 管理人投稿CSV、承認済み読者投稿CSV

## 情報源台帳に必要な項目

```json
{
  "id": "uruma-city",
  "name": "うるま市公式サイト",
  "url": "https://www.city.uruma.lg.jp/",
  "type": "official",
  "method": "rss-or-page",
  "trust": 100,
  "autoPublishEligible": true,
  "enabled": true,
  "lastSuccessAt": null,
  "notes": "石川地区との関連判定を別途行う"
}
```

取得エラー回数、最終成功日時、利用条件の注意も記録できる構造にする。取得先が止まった場合、黙って記事0件として処理せず、取得失敗として残す。

## 変更時の注意

- 新しいサイトを自動取得する前に、RSS、API、利用規約、robotsの順で取得可能性を確認する。
- ログイン、友だち登録、会員登録が必要な情報を自動取得しない。
- 有料記事は見出しと公開範囲の情報だけを扱い、本文を迂回取得しない。
- 取得先に過剰な負荷をかけない。定期実行は原則1日1回とし、失敗時の再試行回数を限定する。
- 情報源の追加は自動掲載許可と同義ではない。最初は候補収集として評価する。
